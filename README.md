# OTAKU

### Breaking Language Barriers in Manga

OTAKU is a smart manga-reading platform designed to reduce language barriers through OCR, language detection, and automatic translation.

## Core Features

- Manga page OCR
- Automatic language detection
- Manga text translation
- Original / translated view
- Personalized manga discovery
- Community features

## Tech Stack

- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB
- OCR: To be implemented
- Translation: To be implemented
